## 🚀 Overview
CADTools for Windows is a Hot Door plugin that brings professional drafting and dimensioning capabilities inside Adobe Illustrator. It lets designers, engineers, and technical illustrators work at real-world scale, measure existing artwork, and attach clear, editable dimension lines without leaving Illustrator. Because it runs as a panel and toolset inside the host application, you keep Illustrator's familiar drawing environment while gaining the accuracy of a dedicated CAD-style workflow.

## ✨ Features
- **Scaled Drawing** — Set a drawing scale so on-canvas measurements always reflect real-world dimensions.
- **Dynamic Dimensioning** — Add dimension lines that recalculate automatically when you resize or edit the underlying art.
- **Precision Measuring** — Read the length, width, area, and perimeter of selected objects with accurate, unit-aware readouts.
- **Unit Flexibility** — Work in inches, millimeters, points, or other units and convert between them on the fly.
- **Technical Drawing Tools** — Use dedicated CADTools drawing and editing tools that complement Illustrator's native toolset.

1. Open or create a document in Adobe Illustrator.
2. Open the CADTools panel from Illustrator's Window menu and choose your drawing scale and units.
3. Select the objects you want to measure or draw at scale.
4. Apply a dimensioning tool to label lengths, offsets, or angles on your artwork.
5. Edit the art and watch the dimensions update to stay accurate.

## ❓ FAQ
**Is CADTools free?**
CADTools is a paid plugin from Hot Door, but you can evaluate it with a free trial. Searches for "CADTools Illustrator free" point to that trial, which runs inside Illustrator for a limited period so you can test the tools before buying a license.

**Which versions of Windows are supported?**
CADTools runs on modern 64-bit Windows releases such as Windows 10 and Windows 11, provided a supported version of Adobe Illustrator is installed on the same machine.

**Is my data secure?**
Your artwork stays in your own Illustrator documents on your Windows PC. CADTools adds its tools to Illustrator and does not take ownership of your files, so your data remains under your control.
